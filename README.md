# morse_quiz

ATtiny202 で動くモールス符号クイズキットのファームウェアです。
ボタン 1 個・圧電スピーカー・LED だけで、モールス符号の聞き取りと打鍵の練習ができます。

## 機能

- **QUIZ モード** — 本機が 1 文字をモールス（音＋LED）で出題し、ボタンで答えを打ちます（短押し＝短点、長押し＝長点）。
  - 正解：「ピンポン」＋LED 点灯 → 次の問題
  - 不正解：「ブー」＋LED 点滅 → 同じ文字を再出題
  - 8 秒間入力がなければ同じ文字を再出題
- **RANDOM モード** — 聞き取り練習用。ランダムな文字を連続で再生します（入力不要）。
- ボタンを **2 秒以上長押し**すると QUIZ ⇔ RANDOM を切り替えます。
- **欧文（A–Z, 26 文字）** と **和文（いろは＋濁点・半濁点, 50 文字）** に対応。
- **速度** 5 / 10 / 15 / 20 WPM（EEPROM に保存）。
- **電池電圧チェック**機能付き。
- QUIZ モードで約 30 秒操作がないと自動でパワーダウン（ボタンで復帰）。RANDOM モードは自動では停止しません。

## 使い方

### 文字セットの選択（電源投入後の最初のボタン操作）

起動音のあと、最初のボタンの押し方で文字セットを選びます。

| 押し方 | 動作 |
|---|---|
| 1 秒未満 | 欧文（A–Z） |
| 1〜5 秒 | 和文。確認音として「ホレ」（`-..---`）を鳴らします |
| 5 秒以上 | 電池チェック（下記） |

選び直すときは電源を入れ直してください。選択後は QUIZ モードから始まります。

### 電池チェック

最初のボタンを 5 秒以上押し続けると、5 秒の時点で音が止まります。ボタンを離すと電源電圧を 0.1 V 単位の 2 桁の数字でモールス送信します（例：「29」＝ 2.9 V）。そのあとは再び最初のボタン操作待ちに戻ります。

### 速度設定

1. ボタンを押したまま電源を入れます。
2. 現在の速度で「V」（`...-`）が鳴ります。
3. 短押しで次の速度に切り替わります（5 → 10 → 15 → 20 → 5 WPM）。
4. 2 秒以上長押しすると EEPROM に保存し（「ピンポン」）、通常どおり起動します。

初期値は 5 WPM です。再生も入力判定も、設定した速度に合わせて動作します。

> **注意:** UPDI でチップ消去すると EEPROM も消えます（EESAVE ヒューズを設定している場合を除く）。消えた場合は 5 WPM に戻ります。

## ハードウェア

マイコン：**ATtiny202**（8 ピン SOIC）

| ピン | ポート | 接続 |
|---|---|---|
| 1 | VDD | 電源 |
| 2 | PA6 | LED（抵抗経由で GND、High で点灯） |
| 3 | PA7 | 押しボタン（GND へ、内部プルアップ使用） |
| 4 | PA1 | 圧電スピーカー端子 A |
| 5 | PA2 | 圧電スピーカー端子 B |
| 6 | PA0 | UPDI（書き込み） |
| 7 | PA3 | 未使用 |
| 8 | GND | GND |

- 圧電スピーカーは PA1 と PA2 を逆位相で駆動します（ブリッジ駆動。振幅が電源電圧の 2 倍になり、約 +6 dB）。
- クロックは工場出荷時設定（20 MHz / 6 = 3.333 MHz）のまま使用します。ヒューズの変更は不要です。
- モールス音の周波数は 741 Hz です（`MORSE_HZ`）。使用する圧電素子の共振周波数に合わせて調整すると音が大きくなります。

## ビルドと書き込み

- 開発環境：MPLAB X IDE（プロジェクトファイル一式は `nbproject/` にあります）
- コンパイラ：XC8 または avr-gcc
- 書き込み器：PICkit 5 など UPDI 対応の書き込み器

MPLAB X でこのフォルダをプロジェクトとして開き、ビルドして書き込んでください。

ビルド済みの HEX ファイルもリポジトリに含めています。ビルドせずに書き込むだけなら、こちらを使ってください。

- [`dist/default/production/morse_quiz.production.hex`](dist/default/production/morse_quiz.production.hex)

## 調整用パラメータ

`morse_quiz.c` の先頭にある定数で動作を変更できます。

| 定数 | 既定値 | 内容 |
|---|---|---|
| `IDLE_REPLAY_MS` | 8000 | 無入力で再出題するまでの時間 (ms) |
| `MODE_HOLD_MS` | 2000 | モード切り替えの長押し時間 (ms) |
| `WABUN_HOLD_MS` | 1000 | 和文を選ぶ長押し時間 (ms) |
| `VDD_HOLD_MS` | 5000 | 電池チェックの長押し時間 (ms) |
| `RANDOM_GAP_MS` | 900 | RANDOM モードの文字間隔 (ms) |
| `POWERDOWN_MS` | 30000 | 自動パワーダウンまでの時間 (ms) |
| `MORSE_HZ` | 741 | モールス音の周波数 (Hz) |
